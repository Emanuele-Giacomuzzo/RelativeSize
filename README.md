# Disturbance and ecosystem size mediate the effects of resource flows in meta-ecosystems

Ecosystem size and resource flows can interact to affect ecosystem function. However, ecosystem size is often correlated with disturbance regime, making it unclear which of these two factors drove the results. Here, we ran a protist experiment with two-patch autotrophic-heterotrophic meta-ecosystems, where their connection (connected/unconnected), patch size (6.43/9.00/15.00/45.00 ml), and disturbed volume (fixed or relative to ecosystem size) were fully crossed. Results showed that both ecosystem size and disturbance type influenced how resource flows affected ecosystem function. First, positive effects of connectivity appeared only in larger ecosystems (15.00 and 45.00 ml) when disturbance was proportional to size. Second, in 9.00 ml-sized ecosystems, benefits occurred only with fixed-volume disturbances. This demonstrates that understanding how resource flows affect ecosystem function requires considering both ecosystem size and disturbance regimes.
